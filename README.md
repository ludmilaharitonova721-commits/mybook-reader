# My Book Reader

My Book Reader — приложение для ведения личной библиотеки и чтения книг.

## Возможности

- Просмотр библиотеки с поиском и сортировкой книг.
- Разделы «Читаю сейчас», «Избранное» и «Коллекции».
- Экран чтения с настройкой шрифта, размера текста и темы.
- Добавление книг и сохранение выбранной темы оформления.
- И��терфейс на русском и английском языках.

## Запуск локально

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

Для production-сборки выполните:

```bash
npm run build
npm start
```

## Стек

Next.js 15, React 19, TypeScript и Tailwind CSS 4.
